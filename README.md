# Hospital-Domain-Entity-Relationship

Data Warehousing and Business Intelligence Coursework -- 03/2026

The following project utilizes conceptual modeling and evaluates the understanding of problems related to data integration and warehousing. The final solution leveraged the design and implementation of OLAP applications to devise an effective multi-dimensional databases for decision making.

Background:

The entity-relationship (ER) model of a simplified hospital domain is shown below. 

A simplified hospital domain provides the design operational system’s database in terms of the main domain elements, Wards and operating theatres (OT), Primary/Principal Diagnosis, Secondary Diagnosis, Consultants, Surgeons Admissions, and Operations-Surgeries. 

The Hospital authorities would like to build a strategic data mart to answer some frequent queries the managers must answer. Such queries are: 

Q1. For each Ward  Year, quarter report the charges per operation, length of stay and admissions cost;  

Q2. For each Ward  Year, quarter report the charges per operation, length of stay and admissions cost of Secondary Diagnosis. 

Solution: 

Based on the ER model of the simplified hospital domain, an integrated dimensional fact model was designed to answer the frequent queries above.
